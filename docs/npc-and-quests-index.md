## Часть 3. Что надо решить завтра (пробелы)

1. **Модели НПС.** Для большинства НПС не выбрана реальная модель из F2/RPU (выбраны: Тед NMBSNP, Келлер NAROBE, Хорриган MABOSS, паладины HAPOWR, Анклав HANPWR). Нужны модели для Хэнка, Рика, лавочника, бармена, доктора, оружейника, бронника, барахольщика, старшего фермера, радиста, инструктора и др. Проверять по правилу «оружие по модели».
2. **Имена.** Безымянные НПС (лавочник, бармен, доктор, оружейник, бронник, барахольщик, радист, фермер) нужны имена и пара фраз для диалогов (resident-phrases.md).
3. **Диалоги.** Написаны только Тед (завязка), Хэнк (прораб) и Рик частично. Остальные: заготовки по квестам, сами диалоги не писались.
4. **Особые карты.** Нужен список карт: логово, овраг самогонщика, будка инструктора, дом с гулями, бункер оружейника, ферма у скал, склад 7, хижина Ходора, ринг Рокки, палаточный лагерь каравана. Сколько делаем в первой версии.
5. **Порядок реализации.** Предлагаю: сначала часы и пульт (test-mode.md), затем Тед и Хэнк с первой стройкой, потом вода, первый набег, охрана и Рик, остальное по секторам.
6. **Рост когтя**, радиорубка и растения у ворот: решения приняты, ждут скриптов.
7. **Открытое по доку:** запасной вариант на случай смерти Теда (описан в решениях 2026-10-04), лимиты торговцев, кража из кассы, ящик с сюрпризом (таблица готова), цены и таймеры воды.
