# Одомашнивание существ для охраны поселения

Статус: черновик 2026-10-03, всё **[пред.]**. Идея Эгора: приручить скорпионов (и позже других врагов) как охрану.

## Скорпион

**Связь.** В Брокен-Хиллз в оригинале есть Профессор, который дрессирует скорпиона (в скриптах счёт обучения по трём характеристикам: ловкость, восприятие, интеллект). Связаться с ним можно только **по радио** через радиовышку поселения. Разговор открывается, если герой прошёл его квест или хотя бы поговорил с ним лично. Штатные города и диалоги не правим: нужна только проверка, что герой с ним говорил (технически: отметка через sfall, проверим).

**Квест «Приручить скорпиона»:**
1. Радио: Профессор объясняет метод (кормить мясом, не бить, показать «хозяина»).
2. Поймать молодого скорпиона: ловушка собирается в мастерской за 300 крышек, поймать нужно скорпиона на карте мира (особая встреча).
3. Привезти его в поселение, дать место (клетка, участок у ворот, 200 крышек).
4. Обучение 4 недели, по неделе на характеристику: ловкость, восприятие, интеллект и послушание. Нужно мясо (1 паёк еды в неделю) и беседы по радио раз в неделю.
5. Результат: **ручной скорпион**, пост «Ворота»: 100% убивает 1 нападающего в набеге (как робот), с ядом. После боя лечение 50 крышек.

Можно завести несколько скорпионов: каждый следующий — повторение квеста (ловушка 300 и обучение).
