# Файлы RPU 2.4.34, к которым мод дописывает свои строки

Взяты из установленной у Егора игры (`mods\rpu.dat`, `mods\rpu_russian.dat`). Сами не меняем: сборка берёт их как есть и дописывает в конец строки из `mod/append/`. Игра читает `city.txt`, `maps.txt`, `scripts.lst` и `map.msg` целиком из последнего архива, поэтому мод кладёт полную копию с нашими строками в конце.

`maps/desert1.map` — заготовка для карты лагеря на этапе М1 (своя копия, оригинал не трогаем).

При обновлении RPU эти файлы нужно взять из новой версии.
